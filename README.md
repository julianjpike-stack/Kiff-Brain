# 🧠 Kiff-Brain

TRIBE v2 brain prediction app — predicts fMRI brain responses to images and videos.

## Requirements

- Windows PC with an NVIDIA GPU
- Python 3.10+ installed from https://www.python.org/downloads/
- Git installed from https://git-scm.com/download/win
- A HuggingFace account with access to the LLaMA 3.2 model

## First Time Setup

1. Install Python and Git using the links above
2. Open a terminal and run:
git clone https://github.com/julianjpike-stack/Kiff-Brain.git
cd Kiff-Brain
3. Double-click `setup.bat` and wait for it to finish (takes 5-10 mins first time)
4. When asked, enter your HuggingFace token

## Running the App

1. Double-click `start.bat`
2. Open your browser and go to `http://localhost:7860`
3. Upload a PNG, JPG or MP4 file and click Run

## Getting Updates

Open a terminal in the Kiff-Brain folder and run:
git pull
